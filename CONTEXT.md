# Federated Policy Vault — glossary pointer

The glossary moved with the rest of the specification on 2026-09-09. It is `CONTEXT.md` in
`btc-policy-spec` (https://github.com/douglaz/btc-policy-spec), beside the numbered requirement
documents and the ADRs. This repository is the Rust reference implementation of that
specification; a term used in a code comment here — Carrier, candidate, Hold, `T`, Lockdown,
release gate, HotClock — is defined there, and a requirement identifier such as `SPN-5` or
`DUR-8` refers to a document there.

Nothing normative is kept in this file so that it cannot drift from the one that is.
